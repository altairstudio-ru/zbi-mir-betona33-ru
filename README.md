# ZBI — Бетонные изделия (ЖБИ)

Одностраничник **zbi.mir-betona33.ru** — производство и поставка бетонных изделий во Владимире и области.

## Стек
- **Astro** (SSG, статический вывод, `trailingSlash: 'always'`)
- **Tailwind CSS** + **shadcn/ui** токены (оранжевая тема `theme-jbi.css`)
- Деплой на **Vercel**

## Локальный запуск
```bash
pnpm install
pnpm exec astro dev
```
Порт: **4322**.

## Сборка
```bash
pnpm exec astro build
```
Сборка в `dist/`.

## Структура
```
src/
├── components/    # UI (Header, Footer, SEO, Button, Section, Card ...)
├── data/          # products.ts — ФБС, категории, FAQ, отзывы, шаги
├── layouts/       # Base.astro (оранжевая тема)
├── pages/         # index.astro — одностраничник (14 блоков)
├── styles/        # base.css (Tailwind)
└── tokens/        # theme-jbi.css (оранжевая палитра)
```

## Продукция
- Фундаментные блоки (ФБС) по ГОСТ 13579-78
- Плиты перекрытия ПК / ПБ
- Товарный бетон М100–М400
- Кольца колодезные, лотки
- Брусчатка, бордюры
- Сваи, балки, перемычки
